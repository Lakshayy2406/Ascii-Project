# 🎨 ASCII Art Maker

A Python command-line application that converts characters and text into colorful **ASCII art** using predefined character patterns.

## ✨ Features
- 🔠 Single uppercase character ASCII art
- 🔤 Uppercase word ASCII art
- 🔡 Lowercase character and word ASCII art
- 🔤 Alphabet ranges such as `A-D`
- 🔢 Number ASCII art
- 🏷️ Name tag generator
- 🔄 Reverse text ASCII art
- 🌈 Colored terminal output

## 🛠️ Tech Stack
- Python
- Colorama
- Terminal / CLI

## 🚀 Installation

```bash
git clone https://github.com/Lakshayy2406/Ascii-Project.git
cd Ascii-Project
pip install colorama
python ascii.py
```

## 📋 Menu

1. Single Character (A-Z)
2. Word (A-Z)
3. Alphabet Range
4. Numbers
5. Name Tag
6. Reverse Text
7. Small Single Character (a-z)
8. Small Word (a-z)
9. Exit

## 🎯 Purpose

This project demonstrates Python functions, input validation, string processing, ASCII character mapping, and terminal formatting.
